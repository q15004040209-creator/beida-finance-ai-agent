# finance-research-agent · 金融投研智能体

> 参赛作品：北大金融AI智能体创新大赛（建议方向一「金融AI智能体算法与应用创新」+ 方向三「金融AI智能体行业场景落地」）

## 一、定位

把"研究一家公司的标准流程"封装成一个可对话的金融 AI Agent。用户用自然语言提问，Agent 走「定位公司 → 财务透视 → 估值判断 → 护城河 → 同行对比 → 风险提示」的投研链路，并额外提供**金融知识问答**与**风控合规初审**两个子能力，形成"一个 Agent，三类金融场景"的复用。

核心差异点：不是单轮问答机器人，而是**遵循固定投研方法论的多步 Agent**——每一步有可验证的输出结构（指标卡片、估值表、风险清单），可被评审"功能验证"与"效果验证"逐项核对。

## 二、场景

- 散户/研究员快速看清一家公司基本面，不想读几十页财报。
- 投资社群/内容创作者把基本面讲成通俗科普。
- 机构贷款/尽调前的财务异常初审。
- 金融小白用自然语言问术语与机制（如"什么是杜邦分析"）。

## 三、能力

| 能力 | 输入 | 输出 |
|---|---|---|
| 投研分析 `research` | 股票代码/公司名 | 业务画像 + 三表透视 + 指标卡片(好/中/警) + 估值 + 护城河 + 同行对比 + 风险提示 |
| 金融知识问答 `qa` | 自然语言问题 | 术语/方法/机制解释 + 举例 |
| 风控合规初审 `compliance` | 财报/公告要点 | 分级风险信号清单 + 建议核查动作 |

## 四、技术底座

- 通用 LLM + 结构化输出（few-shot + 固定 JSON schema）。
- 投研框架：杜邦分析、简化 DCF、Morningstar 式护城河。
- 风控规则：现金流背离、商誉高悬、审计非标、负债率跳升等公认预警特征。
- 可接行情/财报 API 做 RAG；离线凭用户提供材料亦可运行。
- 交付形态：SKILL.md 定义 Agent 行为，可经 MCP/CLI 调用，满足"可运行、可展示、可验证"评审要求。

## 五、运行说明

1. 准备一个支持系统提示词（system prompt）的 LLM 运行环境（OpenAI 兼容 / 本地推理均可）。
2. 将 `finance-research-agent/SKILL.md` 的正文作为 Agent 的 system prompt 载入。
3. 用户以自然语言提问，例如："分析 600519" / "什么是杜邦分析" / "帮我初审这家公司的财报风险"。
4. Agent 按 SKILL.md 定义的链路逐步输出结构化结果；可把输出固定为 JSON 以便二次处理。
5. 可选：接入财报检索 API，让 `research` 步骤自动拉取最新数据（RAG 增强）。

## 六、测试样例

**样例 1（投研）**
- 输入：`分析 600519`
- 期望输出含：业务画像段、ROE/毛利率/负债率指标卡片（标好/中/警）、估值段、护城河段、风险提示段 + "研究用途非投资建议"声明。

**样例 2（知识问答）**
- 输入：`用一句话解释 PE 和 PB 的区别`
- 期望输出：PE=市值/净利润（看盈利贵贱），PB=市值/净资产（看账面贵贱），并各举一例。

**样例 3（风控初审）**
- 输入：`这家公司连续三年经营现金流为负、商誉占净资产 60%，有什么风险？`
- 期望输出：列出"利润含金量低""商誉减值风险高"等分级信号 + 建议核查动作，不下合规结论。
