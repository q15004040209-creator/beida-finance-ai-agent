# 金融投研智能体（finance-research-agent）

> 本 Skill 为「北大金融AI智能体创新大赛」参赛作品，对应赛事建议方向一「金融AI智能体算法与应用创新（投研分析智能体 / 多智能体协作）」与方向三「金融AI智能体行业场景落地（智能投顾 / 风控合规场景的智能审查工具 / 金融知识问答 Agent）」。

## 一、定位（定位 / 场景 / 能力 / 技术底座 / 运行说明 / 测试样例）

**定位**：把"看一家公司的研究流程"封装成可对话 Agent——用户用自然语言提问，Agent 走「定位公司 → 财务透视 → 估值判断 → 护城河 → 同行对比 → 风险提示」的标准投研链路，并额外提供金融知识问答与风控合规初审两个子能力，形成"一个 Agent，三类金融场景"的复用。

**场景**：
- 散户/研究员想快速看清一家公司基本面，不想读几十页财报。
- 投资社群/内容创作者需要把基本面讲成通俗科普。
- 机构做贷款/尽调前的合规初审（财务异常、信披风险扫描）。
- 金融小白用自然语言问"什么是 ROE、DCF 怎么估"。

## 二、能力清单

1. **投研分析（research）**：输入代码/名称 → 业务画像 + 三张表透视（利润/资产/现金流）+ 核心指标卡片（ROE/毛利率/负债率/增速，好中警三色）+ 估值（PE/PB/PS + 简化 DCF）+ 护城河判断 + 同行对比 + 风险提示。全程标注"研究/教育用途，非投资建议"。
2. **金融知识问答（qa）**：解释金融术语、指标含义、估值方法、市场机制，给出可举例的说明，不喊买卖点。
3. **风控合规初审（compliance）**：基于公开财报与公告，扫描财务异常信号（经营现金流长期为负、商誉占比过高、关联交易异常、负债率跳升、审计非标意见），输出分级风险清单与建议核查动作；仅做"提示信号"，不下合规结论。

## 三、工作流（投研链路）

1. **定位公司**：一句话业务画像 + 行业 + 产业链位置，避免一上来堆数字。
2. **三张表透视**：
   - 利润表：营收/归母净利趋势、增速质量（非经常性损益占比）、毛利率/净利率变化。
   - 资产负债表：资产负债率、有息负债、商誉占比、现金短债比（暴雷预警）。
   - 现金流量表：经营现金流是否为正且覆盖净利润（利润含金量）、资本开支强度。
3. **指标卡片**：ROE（杜邦拆解：净利率×周转×杠杆）、毛利率、负债率、营收增速，标注好/中/警。
4. **估值**：PE/PB/PS 同业对比 + 简化 DCF（自由现金流×折现）判断贵贱，明确"低 PE 可能是价值陷阱"。
5. **护城河**：用"无形资产/转换成本/网络效应/成本优势/规模优势"框架判断可持续竞争优势。
6. **同行对比**：同行业 2-3 家横向打分，指出谁更"能打"。
7. **风险提示**：结构化列出业务/财务/估值/政策四类风险，强制附"非投资建议"声明。

## 四、示例

用户：分析一下贵州茅台（600519）。
Agent 输出（节选）：
- 业务画像：以茅台酒为核心的高端白酒，强品牌护城河，产业链上游农产品、下游经销+直营。
- 指标卡片：ROE ≈ 30%（好）、毛利率 >90%（好）、负债率 <30%（好）、营收增速双位数（好）。
- 估值：PE 处历史中枢，DCF 显示现金流极厚，护城河=无形资产（品牌）+ 成本优势（老窖池）。
- 风险：政策限价/消费税改革、消费场景波动；声明"研究用途，非买卖建议"。

用户：什么是杜邦分析？
Agent：把 ROE 拆成 净利率×总资产周转×权益乘数，分别看"赚得厚不厚/转得快不快/杠杆高不高"，定位 ROE 来源。

## 五、边界

- 仅做研究与教育用途，不提供具体买卖点、不预测短期涨跌、不代客理财、不涉内幕信息。
- 数据以用户提供的财报/公告为准；不承诺实时行情，重大决策请交叉核验。
- 风控初审只"提示信号"，不构成合规结论或法律意见。
- 不要求用户粘贴账户、密钥等敏感信息。

## 六、技术底座

- 基于通用 LLM 的金融语义理解与结构化输出（few-shot + 固定 JSON schema）。
- 投研框架采用杜邦分析、简化 DCF、护城河（Morningstar 式）等成熟方法论。
- 风控信号规则来自财务异常的公认预警特征（现金流背离、商誉高悬、审计非标等）。
- 可对接外部行情/财报 API 作为检索增强（RAG），离线时凭用户提供材料亦可运行。
